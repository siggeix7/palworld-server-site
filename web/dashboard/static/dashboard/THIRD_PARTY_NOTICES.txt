RNZ01/palworld-server-dashboard
https://github.com/RNZ01/palworld-server-dashboard
Upstream revision: 588fa6390e0c5b6fe909e2c1fd3baddb86ef92c8

This site adapts portions of the upstream map interaction, player palette and
roster behavior, FPS health model, payload normalization, themes, static map
projection and Palpagos overview. The implementations were modified for a read-only,
privacy-sanitized Django architecture. Detailed source paths, changes,
asset hashes and exclusions are recorded in the distributed NOTICE.md.

LukeHollandDev/palworld-live-map
https://github.com/LukeHollandDev/palworld-live-map
Upstream revision: 19f3e3f8e684481bde58fef6c76845f811d57614

The World Tree overview bounds and a minimized catalogue of 1,146 static
locations in 11 categories were generated from its reproducible Palworld 1.0.1
asset export. Search, filtering, details, culling, clustering and responsive
explorer behavior were implemented locally for the existing Django map after
reviewing the upstream interface. No React, Go application or exporter code is
included. Exact source/output hashes, bounds and data counts are in NOTICE.md.
The minimized JSON output SHA-256 is
c3b747e3f1686952e1a871c6785779275ef087af07caab44db260afdf5cb02e6.
