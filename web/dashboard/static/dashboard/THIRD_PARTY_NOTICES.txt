LukeHollandDev/palworld-live-map
https://github.com/LukeHollandDev/palworld-live-map
Upstream revision: 369ac4085a451ad546d3cee5d08952f36e4b2282 (v1.2.3)

The site adapts the upstream React map interface into the unified dashboard SPA,
uses the original 8192x8192 Palpagos and World Tree images, and includes a
minimized projection of 1,146 static locations in 11 categories, verified
against Palworld 1.0.3.101283. The client uses authenticated Django APIs backed
only by sanitized snapshots. No upstream Go server, save reader, GPL leaderboard
patch or exporter source is included.
The container build adapts the deterministic WebP tile pyramid, spatial marker
indexing, adaptive clustering, exploration checklist, private character claims,
share-position links, in-game coordinates and the v1.2.2 native drag fix. The
original JPEGs remain unchanged. The projected catalogue adds only the local
privacy-safe height and reward fields described in NOTICE.md.
Upstream v1.2.3 supports Palworld 1.0.4 composite tables in its excluded asset
exporter, but still ships the 1.0.3 catalogue while updated community mappings
are unavailable. This site preserves that verified provenance and reports the
compatibility gap rather than relabeling old locations.
Exact source/output hashes, modifications and data counts are in NOTICE.md.
