LukeHollandDev/palworld-live-map
https://github.com/LukeHollandDev/palworld-live-map
Upstream revision: 8ad00dbba656bdb404bc52e11a361004406c5f92 (v1.1.0)

The site adapts the upstream React map interface into the unified dashboard SPA,
uses the original 8192x8192 Palpagos and World Tree images, and includes a
minimized projection of 1,146 static locations in 11 categories, verified
against Palworld 1.0.3.101283. The client uses authenticated Django APIs backed
only by sanitized snapshots. No upstream Go server or exporter source is
included.
The container build adapts the v1.1.0 deterministic WebP tile pyramid and the
client's spatial marker indexing, adaptive clustering and independent catalogue
loading, plus lazy Explorer sections and bounded search results. The original
JPEGs and projected catalogue remain byte-for-byte unchanged.
Exact source/output hashes, modifications and data counts are in NOTICE.md.
The projected catalogue SHA-256 is
